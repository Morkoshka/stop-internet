# Ручные тесты

[English](testing.md) | Русский

Всё, что ставит фильтры или службы, проверяется вручную на реальной машине.
Модульные тесты покрывают логику, а эти шаги — то, что может показать только
Windows. Для каждого шага сказано, что он меняет, как его откатить и чего
ожидать.

Здесь описана проверка службы Windows (шаг 4 плана), значка в трее с
переключением режимов и автоматическим выбором режима (шаг 5) и
установщика с аварийным отключением (шаг 6). Полный чек-лист с записью
трафика появится на шаге 7.

## Перед началом

- Сборка: `cargo build --release`. Команды ниже запускайте из папки
  репозитория в PowerShell **от имени администратора** и не закрывайте это
  окно до конца проверки. Чтобы короткая команда `stopinet` работала в этом
  окне, после установки (шаг A1) выполните:

  ```powershell
  Set-Alias stopinet 'C:\Program Files\stop-internet\stopinet.exe'
  ```

  Это псевдоним только для текущего окна PowerShell, в системе ничего не
  меняется. До установки вместо `stopinet` пишите
  `.\target\release\stopinet.exe`.
- Положите свою конфигурацию в `config\stopinet.local.toml` (git её
  игнорирует) и сначала проверьте её пробным запуском:
  `.\target\release\stopinet.exe trial --config config\stopinet.local.toml`.
- Аварийный выход, работает без сети:

  ```powershell
  & 'C:\Program Files\stop-internet\stopinet.exe' panic
  ```

  Он останавливает службу и снимает все фильтры stop-internet, включая
  постоянные. `.\target\release\stopinet.exe panic` делает то же самое.
- Значок говорит на языке интерфейса Windows: на русской Windows
  по-русски, на остальных по-английски. Шаги цитируют русские тексты.
- На что смотреть:
  - `stopinet status`: состояние службы, режим, объекты stop-internet в Base
    Filtering Engine, состояние туннеля. Ничего не меняет.
  - `Get-Content C:\ProgramData\stop-internet\service.log -Tail 20`: журнал
    службы. Адресов в нём нет, им можно делиться.

## A. Служба в режиме session-only

Ничего постоянного: остановка службы, её падение или перезагрузка оставляют
машину без фильтров stop-internet.

| # | Действие | Ожидание |
|---|---|---|
| A1 | `.\target\release\stopinet.exe install --config config\stopinet.local.toml --session-only` | «service running». Что меняется: программы в `C:\Program Files\stop-internet`, конфигурация в `C:\ProgramData\stop-internet` (запись только у администраторов), служба `stopinet` с автоматическим запуском. Откат: `stopinet uninstall`. |
| A2 | `stopinet status` | служба running, start AutoStart, session-only; provider и sublayer «session»; 0 persistent, 0 boot-time, сколько-то session-фильтров; туннель — как в Happ. |
| A3 | Отключить Happ, открыть сайт, подключиться снова | Сайты перестают открываться примерно за 2 с; после подключения снова открываются. В журнале «tunnel down» и «tunnel up». |
| A4 | `Stop-Service stopinet`, затем `stopinet status` | Фильтров нет, интернет без ограничений. `Start-Service stopinet` возвращает их. |
| A5 | `Stop-Process -Name stopinet-service -Force` | Примерно через 5 с служба снова работает (`stopinet status`), в журнале новый запуск. |
| A6 | Сон, пробуждение | В журнале «woke up, mode TunnelOnly»; туннель отслеживается как раньше. |
| A7 | Перезагрузить Windows | Служба запускается сама; до её запуска интернет открыт (session-only). |

## B. Постоянный базовый набор

| # | Действие | Ожидание |
|---|---|---|
| B1 | `stopinet install` (оставляет установленную конфигурацию) | «service running». `stopinet status`: provider и sublayer «persistent», сколько-то постоянных фильтров, столько же boot-time копий (или 0 и примечание в журнале), сверху session-фильтры. Откат: `stopinet panic` или `stopinet uninstall`. |
| B2 | **Сначала аварийный выход:** `stopinet panic`, затем `stopinet status` | Нет провайдера, нет подуровня, 0 фильтров; интернет без ограничений. `Start-Service stopinet` возвращает к состоянию B1. Если это не работает, дальше не идите. |
| B3 | `Stop-Service stopinet` | Интернет закрыт, подключён Happ или нет. Приложения из `direct` работают, только если Happ отключён: подключённый Happ ведёт их через `happd.exe`, а он сейчас закрыт. `stopinet status`: постоянные фильтры на месте, 0 session. `Start-Service stopinet` возвращает интернет через туннель. |
| B4 | `Stop-Process -Name stopinet-service -Force` | Примерно 5 с всё закрыто, потом служба снова работает и туннель работает. |
| B5 | Отключить Happ; выполнить `Resolve-DnsName example.com -DnsOnly` | Пока туннеля нет, имя не разрешается и сайты не открываются; приложение из `direct` сохраняет свои соединения. После подключения всё работает. |
| B6 | Сон, пробуждение | Как в A6; до возвращения туннеля ничего не проходит. |
| B7 | Перезагрузить Windows, затем завершить работу и включить (Fast Startup) | Пока Happ не подключился, ничего не открывается; после подключения всё работает. В журнале оба раза — новый запуск службы и установка базового набора. |
| B8 | `stopinet uninstall` | «service removed», все фильтры сняты, программы удалены; конфигурация и журнал остаются в `C:\ProgramData\stop-internet`. |

## C. Значок в трее и режимы

Служба установлена с постоянным базовым набором, как после B1. Соберите новую
версию и установите её из окна администратора; установленная конфигурация
остаётся. Несколько шагов выполняются в обычном окне PowerShell, без прав
администратора; это сказано в самом шаге.

| # | Что сделать | Чего ждать |
|---|---|---|
| C1 | `cargo build --release`, затем `.\target\release\stopinet.exe install` | «tray icon set to start at every sign-in», «service running», «tray icon started». В области уведомлений появляется значок-щит, возможно под стрелкой ^ (перетащите его к часам, чтобы он всегда был виден). Что меняется: `stopinet-tray.exe` в `C:\Program Files\stop-internet`, значение `stop-internet` в `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run`. Откат: `stopinet uninstall` или выключить `stopinet-tray` в Диспетчере задач, «Автозагрузка приложений». |
| C2 | Навести мышь на значок; `stopinet status` | При подключённом Happ: зелёный щит с галочкой, подсказка «Только туннель», «интернет через VPN»; `status` показывает `mode: tunnel only, tunnel up`. По щелчку меню открывается левым краем у курсора и целиком над панелью задач; при тёмной теме приложений Windows меню тёмное. |
| C3 | Отключить Happ, затем подключить снова | Примерно за 2 с щит становится красным с крестиком, «туннеля нет, интернет закрыт»; после подключения снова зелёный. |
| C4 | В обычном PowerShell: `& 'C:\Program Files\stop-internet\stopinet.exe' status`, затем то же с `mode normal --minutes 1` | `status` тоже показывает режим: канал пускает интерактивного пользователя. `mode normal` отклоняется: «normal internet lowers protection: run this from an elevated terminal». В журнале «normal internet refused». Ничего не меняется. |
| C5 | Меню значка: Прокси | Круглая отметка переходит на «Прокси», щит остаётся зелёным; в журнале «mode Proxy asked». Если в Happ включён режим системного прокси (TUN выключен), сайты открываются через прокси, а `stopinet policy --mode proxy` показывает правило «Windows DNS client (svchost.exe, port 53)»; приложения, которые прокси не используют (например, Telegram без настроенного прокси), остаются заблокированы. Обратно: меню, «Только туннель». |
| C6 | Меню: «Обычный интернет», «На 15 минут»; в окне UAC (программа `stopinet-tray.exe`, издатель неизвестен) ответить **Нет** | Ничего не меняется. |
| C7 | То же, ответить **Да** | Щит становится серым с чертой, подсказка «Защита выключена», «ещё 15 мин»; при отключённом Happ сайты открываются напрямую. В журнале «normal internet for 15 min, asked by an administrator». Обратно: меню, «Только туннель», без запроса UAC. |
| C8 | Отключить Happ. В окне администратора: `stopinet mode normal --minutes 1`; начать в браузере большую загрузку или видео; подождать | Через минуту и не больше чем 2 с сверху щит краснеет, в журнале «normal internet time is up», загрузка или видео останавливается: возврат в защищённый режим рвёт прямые соединения. Снова подключить Happ. |
| C9 | Меню: «Прокси»; сон, пробуждение | По-прежнему «Прокси» (в журнале «woke up, mode Proxy»). Затем меню: «Обычный интернет», «До перезагрузки или сна» (UAC), снова сон и пробуждение: в журнале «woke up, mode TunnelOnly», щит зелёный или красный. |
| C10 | «Обычный интернет» до перезагрузки, как в C9, затем выйти из системы (Пуск, ваше имя, «Выйти») и войти снова | В журнале «user logged on, mode TunnelOnly». Значок после входа запускается сам. |
| C11 | «Обычный интернет» до перезагрузки, затем «Завершение работы» и включение (Fast Startup) | После включения «только туннель»: в журнале новый запуск службы или «user logged on, mode TunnelOnly». |
| C12 | `Stop-Service stopinet`, посмотреть на значок, затем `Start-Service stopinet` | Пока служба остановлена: красный щит, «Служба остановлена», в меню доступны только журнал и закрытие. После запуска через секунду-две значок снова следует за туннелем. |
| C13 | Меню: «Журнал службы»; затем меню: «Закрыть значок» | Журнал открывается в Блокноте. Закрытие убирает только значок; `stopinet status` по-прежнему показывает работающую службу. Снова запустить значок: Win+R, `"C:\Program Files\stop-internet\stopinet-tray.exe"`. Повторный запуск второго значка не добавляет. |
| C14 | Необязательно: `stopinet uninstall`, затем снова установить, как в C1 | Значок исчезает, «tray icon no longer starts at sign-in»; в Диспетчере задач в «Автозагрузке приложений» его больше нет. `install` возвращает службу, базовый набор и значок. |
| C15 | «Параметры», «Персонализация», «Цвета»: переключить «Выберите режим» между тёмным и светлым, после каждого переключения открыть меню значка | Меню следует теме приложений: тёмное, потом светлое. Затем вернуть прежний режим. |

## D. Автоматический выбор режима

Пункт «Автоматически» в меню значка сам переключает «только туннель» и
«Прокси» вслед за системным прокси Windows. Что выставляет Happ, видно в
«Параметрах», «Сеть и Интернет», «Прокси-сервер»: в режиме системного прокси
включено «Использовать прокси-сервер» с адресом loopback, например
127.0.0.1. Начните с Happ, подключённого в режиме TUN. Выбор режима в меню
выключает «Автоматически»; перед следующим шагом включите его снова.

| # | Что сделать | Чего ждать |
|---|---|---|
| D1 | `cargo build --release`, затем `.\target\release\stopinet.exe install`; открыть меню значка | У «Автоматически» стоит галочка, круглая отметка на «Только туннель», щит зелёный. Ничего нового не записано: настройка появляется в `HKCU\Software\stop-internet`, только когда меняется. |
| D2 | В Happ переключиться на режим системного прокси (TUN выключен) | Примерно за 2 с круглая отметка переходит на «Прокси», щит зелёный, «открыт только прокси клиента»; сайты открываются. В журнале «mode Proxy asked». Между выключением TUN и включением прокси щит может на мгновение покраснеть. |
| D3 | В Happ вернуться на TUN | Отметка возвращается на «Только туннель», щит зелёный, когда туннель поднят; в журнале «mode TunnelOnly asked». Если отметка осталась на «Прокси», Happ держит системный прокси включённым и в режиме TUN: это безвредно, но стоит отметить. |
| D4 | В режиме системного прокси отключить Happ, затем подключить снова | «Только туннель», щит красный, сайты не открываются; после подключения снова «Прокси». Если после отключения отметка осталась на «Прокси», Happ не выключил системный прокси: это всё равно безопасно, на нём никто не слушает. |
| D5 | Happ в режиме системного прокси. Меню: «Только туннель» | Галочка у «Автоматически» пропадает, режим остаётся «Только туннель», сайты перестают открываться. В обычном PowerShell `Get-ItemProperty HKCU:\Software\stop-internet` показывает `FollowSystemProxy : 0`. Затем меню: «Автоматически»: галочка возвращается, через секунду «Прокси», `FollowSystemProxy : 1`. Откат: `Remove-Item HKCU:\Software\stop-internet` удаляет настройку, и она снова считается включённой. |
| D6 | Happ в режиме системного прокси, «Автоматически» включено. В окне администратора: `stopinet mode normal --minutes 1` | Всю минуту щит серый: трей не трогает «обычный интернет». Потом в журнале «normal internet time is up» и примерно через 2 с «mode Proxy asked»; щит зелёный. |
| D7 | Happ в режиме TUN, «Автоматически» включено. В окне администратора: `stopinet mode proxy` | В течение секунды трей возвращает «Только туннель»; в журнале оба запроса. Пока «Автоматически» включено, так и должно быть. |
| D8 | Happ в режиме системного прокси. `Restart-Service stopinet` | В журнале новый запуск службы в режиме «только туннель» и примерно через 2 с «mode Proxy asked». |
| D9 | Меню: «Закрыть значок», снова запустить значок, как в C13, открыть меню | «Автоматически» в том же положении, что и до закрытия. Выключить его, закрыть значок и запустить снова: по-прежнему выключено. В конце включить обратно. |

## E. Установщик и восстановление

Установщик подхватывает установку, сделанную `stopinet install`, поэтому
начинайте как после D1: постоянный базовый набор и ваша конфигурация
установлены. Для сборки нужен Inno Setup 6.4 или новее (`winget install
--id JRSoftware.InnoSetup -e`); сборка ничего не меняет вне `target\`.
Шаги E2–E7 работают и при запуске установщика двойным щелчком в
Проводнике.

| # | Что сделать | Чего ожидать |
|---|---|---|
| E1 | `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-installer.ps1` | «Built target\installer\stop-internet-0.1.0-setup.exe». |
| E2 | `.\target\installer\stop-internet-0.1.0-setup.exe`; UAC: «Да» (неизвестный издатель); «Пробный режим» не включать; «Установить» | Мастер говорит на языке интерфейса Windows. На странице «Всё готово к установке» — «Конфигурация: оставить C:\ProgramData\stop-internet\config.toml». Несколько секунд «Подготовка к установке»: значок исчезает и появляется снова. `stopinet status`: running, persistent, те же фильтры, что и до установки; в журнале остановка и новый запуск; конфигурация не изменилась. Изменения: в меню «Пуск» папка «stop-internet» с тремя ярлыками, «stop-internet» в «Параметры → Приложения», в `C:\Program Files\stop-internet` — `docs\`, `config.example.toml`, `LICENSE.txt` и `unins000.*`. Откат: E9. |
| E3 | Меню «Пуск»: «stop-internet — инструкция по восстановлению»; затем «stop-internet» | Инструкция открывается в Блокноте, на языке мастера. Второй ярлык не добавляет второй значок. |
| E4 | Запустить установщик ещё раз | Как в E2: обновление поверх себя. В «Приложениях» stop-internet по-прежнему один. |
| E5 | Меню «Пуск»: «stop-internet — аварийное отключение». Ответить **«Нет»**; потом ещё раз — **«Да»** и **«Нет»** в запросе UAC | Ничего не меняется, `stopinet status` как раньше. |
| E6 | То же, **«Да»** и в UAC **«Да»** | Сообщение «Защита выключена: служба остановлена, фильтры stop-internet удалены». `stopinet status`: stopped, provider none, 0 фильтров; значок красный, «Служба остановлена»; сайты открываются и с отключённым Happ. Проверка `netsh wfp` из [инструкции по восстановлению](recovery.ru.md#проверить-что-ничего-не-осталось) показывает 0. `Start-Service stopinet`: защита снова включена, счётчик больше 0. |
| E7 | Сломанная конфигурация: `Set-Content $env:TEMP\broken.toml 'tunnel = ['`, затем `.\target\installer\stop-internet-0.1.0-setup.exe /CONFIG="$env:TEMP\broken.toml"`, «Установить» | На странице «Всё готово к установке» указан этот файл. Установщик останавливается на «Подготовке к установке» с «stopinet install не завершился» и ошибкой разбора. Ничего не меняется: `stopinet status` как в E2, второй записи в «Приложениях» нет. Откат: `Remove-Item $env:TEMP\broken.toml`. |
| E8 | Тихое обновление: `(Start-Process .\target\installer\stop-internet-0.1.0-setup.exe '/VERYSILENT' -Wait -PassThru).ExitCode` | `0`, без окон; `stopinet status` как в E2. |
| E9 | «Параметры → Приложения» → stop-internet → «Удалить»; на вопрос об удалении конфигурации ответить **«Нет»** | Значок исчезает. `Get-Service stopinet` ничего не находит, проверка `netsh wfp` показывает 0, `C:\Program Files\stop-internet` и папки в меню «Пуск» больше нет, `C:\ProgramData\stop-internet` остаётся. Сайты открываются и с отключённым Happ. |
| E10 | Запустить установщик с включённым «Пробным режимом» | `stopinet status`: session-only, provider «session». `Stop-Service stopinet` снимает все фильтры, `Start-Service stopinet` возвращает их. Потом запустить его ещё раз с выключенным «Пробным режимом» (мастер помнит прошлый выбор): persistent, как в E2. |
